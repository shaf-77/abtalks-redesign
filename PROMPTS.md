# ABTalks — Development Prompts

This file documents the main prompts and instructions used during the design and development of the ABTalks website.

---

## 1. Website Concept

Create a modern learning and accountability platform called ABTalks based around a 60-day learning journey.

The website should encourage users to learn consistently, complete practical challenges, build projects, track progress, and maintain daily momentum.

The overall experience should feel clean, minimal, motivating, and focused on turning learning into visible proof of work.

---

## 2. Landing Page

Create a landing page for the ABTalks 60-day journey.

Include:

- ABTalks branding
- Strong hero section
- 60-day learning message
- Clear call-to-action to start the journey
- Supporting statistics
- Clean and modern visual hierarchy
- Responsive layout for desktop and mobile

The landing page should communicate the idea of building a stronger version of yourself through consistent daily action.

---

## 3. 60-Day Journey

Create a learning journey system where users can:

- Start a 60-day journey
- View their current day
- View remaining days
- Track overall progress
- See their current streak
- Complete daily challenges
- Maintain consistency throughout the journey

The starting experience should begin at Day 1.

---

## 4. Dashboard

Create a personal dashboard that gives users an overview of their learning journey.

Include:

- Current journey day
- Days remaining
- Current streak
- XP
- Ranking
- Progress
- Daily challenge
- Achievements
- Activity heatmap
- Learning schedule
- Minimum Win
- Reality Check
- Mood tracking

Use a clean card-based layout with strong visual hierarchy.

---

## 5. Streak System

Create a streak tracking component.

The component should:

- Display the current streak
- Show a fire indicator
- Display personal best
- Show visual progress
- Encourage users to maintain daily momentum

The initial journey state should use a Day 1 / 1-day starting state rather than showing an already completed streak.

---

## 6. Daily Challenge

Create a daily challenge card and challenge page.

Each challenge should contain:

- Day number
- Challenge title
- Category
- Description
- Estimated time
- Difficulty
- Challenge requirements
- Start challenge action
- Submission section

Challenges should focus on practical work and building projects that learners can actually show.

---

## 7. Challenge Submission

Create a submission interface where learners can submit their completed challenge.

The submission experience should be simple and clearly connected to the daily challenge.

---

## 8. Progress Tracking

Create a progress section that shows:

- Current day out of 60
- Progress bar
- XP
- Streak
- Ranking
- Weekly activity

The progress indicators should be visually clear and easy to understand.

---

## 9. Activity Heatmap

Create a GitHub-style activity heatmap to visually represent learning activity.

The heatmap should help users understand:

- Active days
- Consistency
- Gaps in activity
- Overall learning activity

---

## 10. Achievements

Create achievement cards that represent milestones reached during the learning journey.

Achievements should provide visual motivation and complement the XP and progress systems.

---

## 11. Minimum Win

Create a Minimum Win section that encourages the learner to complete one meaningful action each day.

The purpose is to help users maintain momentum even when they cannot complete a large amount of work.

---

## 12. Reality Check

Create a Reality Check section that encourages learners to honestly evaluate their progress and consistency.

The design should encourage reflection rather than simply showing numerical progress.

---

## 13. Mood Selector

Create a simple mood selector that allows users to record how they feel during their learning journey.

The component should be visually simple and easy to interact with.

---

## 14. Learning Schedule

Create a schedule timeline showing planned learning sessions.

Include:

- Learning sessions
- Session duration
- Weekday schedule
- Weekend schedule
- Timeline-style presentation

---

## 15. Navigation

Create responsive navigation for the application.

Include:

- ABTalks branding
- Main navigation
- Dashboard navigation
- Challenge navigation
- Mobile bottom navigation

The navigation should work across desktop and mobile layouts.

---

## 16. UI Design

Use a clean, modern, minimal interface.

Design principles:

- Strong typography
- Clear visual hierarchy
- Card-based sections
- Rounded elements
- Consistent spacing
- Progress indicators
- Minimal distractions
- Responsive layouts
- Focus on readability and usability

---

## 17. Responsive Design

Make the website responsive across:

- Desktop
- Tablet
- Mobile

Ensure cards, navigation, progress sections, challenges, and dashboard content adapt properly to smaller screens.

---

## 18. Technology

Build the frontend using:

- React
- Vite
- JavaScript / JSX
- React Router
- Tailwind CSS
- Lucide React

Use reusable React components wherever possible.

---

## 19. Data

Use mock/local data for the current frontend experience.

Keep challenge information, learner information, achievements, and other demonstration data organized separately from UI components where practical.
